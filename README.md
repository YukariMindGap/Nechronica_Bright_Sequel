# Nechronica: Bright Sequel
New and reworked version of the fork for Malkeus's Compatible Nechronica, made with Cataclysm: Bright Nights in mind.

It's a mod based of the Japanese TTRPG about zombie girls (called Dolls) in a post-apocalyptic world fighting against zombies and other monsters employed by the Necromancer (the DM). With that kind of premise, things get weird very fast.

The difference between the old fork and this one is that this mod will mainly be compatible with Cataclysm: Bright Nights, as that fork is what i'm focusing on, and this one fixes all the problems with the old mod.
